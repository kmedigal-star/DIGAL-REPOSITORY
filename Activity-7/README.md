## 💭 Reflection

Testing both **ChatGPT** and **Gemini** with the same Operating Room Nurse resume prompt highlighted clear differences in how each tool handles dense clinical details. ChatGPT produced a neat draft by sticking closely to the input, but packed the bullet points tightly together. Gemini grouped rotations into clearer sections and offered practical recruiter-perspective feedback—trimming outdated elementary/high school awards, catching a timeline mismatch between graduation year and license status, and noting how an abroad-focused seminar might look to local hiring managers. Comparing both outputs reinforced that running the same prompt across multiple AI tools yields stronger results, while still requiring careful manual verification of clinical timelines and credentials.
